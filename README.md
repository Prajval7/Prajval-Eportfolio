# Prajval Srivastava — Vilen-inspired Streamlit Portfolio

Original adaptation inspired by the visual principles of vilendesign.com: minimal editorial layout, oversized type, a selected-work index, restrained chrome, and in-place project details.

## Repository structure
Upload the entire folder:
- `streamlit_app.py`
- `requirements.txt`
- `README.md`
- `assets/`
  - `profile.png`
  - `Prajval_Srivastava_Resume.docx`
  - the 3 project Excel files

## Project behavior
"Open project ↗" is a Streamlit control using session state. It stays on the same portfolio page. The project detail includes problem, work, tools, output, evidence, original workbook download, and an in-page workbook inspection.

No dashboard screenshots are used.
